# CS336 Assignment 1: Basics Implementation

This repository contains my implementation of the CS336 Assignment 1 basics stack:

- byte-level BPE tokenizer training;
- BPE tokenizer encoding and decoding;
- core Transformer language model modules;
- optimizer, loss, batching, checkpointing, and training loop utilities;
- decoding / text generation utilities;
- profiling and FLOPs accounting helpers.

The implementation is mainly in [`cs336_basics/`](./cs336_basics).

## Implementation Summary

### BPE Tokenizer Training

Implemented in [`cs336_basics/BPE.py`](./cs336_basics/BPE.py).

This part trains a byte-level BPE tokenizer from raw text and returns:

- `vocab: dict[int, bytes]`
- `merges: list[tuple[bytes, bytes]]`

Main features:

- GPT-2-style pre-tokenization regex;
- special-token splitting so BPE merges do not cross document boundaries;
- byte-level vocabulary initialization with the 256 single-byte tokens;
- optional multiprocessing for pre-tokenization over large files;
- pair-count based merge training;
- optimized pair updates using an inverted index from pair to affected word indices;
- bucket-style tracking of high-frequency pairs to reduce repeated full `max(pair_count)` scans.

### Tokenizer Encode / Decode

Implemented in [`cs336_basics/tokenizer.py`](./cs336_basics/tokenizer.py).

Main features:

- tokenizer construction from in-memory `vocab` and `merges`;
- `from_files(...)` loading serialized vocab and merge files;
- special-token aware encoding;
- support for overlapping special tokens by matching longer special tokens first;
- BPE merge application by learned merge rank;
- byte-safe decoding with UTF-8 replacement behavior;
- `encode_iterable(...)` for streaming token IDs from an iterable of strings.

### Transformer Model Components

Implemented in [`cs336_basics/Transformer.py`](./cs336_basics/Transformer.py).

Implemented modules include:

- `Linear`
- `Embedding`
- `RMSNorm`
- `SwiGLU` feed-forward network
- numerically stable `softmax`
- scaled dot-product attention
- RoPE positional encoding
- multi-head self-attention with RoPE
- Transformer block
- Transformer language model

The model follows a decoder-only pre-norm Transformer layout:

```text
token IDs
-> embedding
-> repeated Transformer blocks
   -> RMSNorm
   -> MHA with RoPE
   -> residual
   -> RMSNorm
   -> SwiGLU FFN
   -> residual
-> final RMSNorm
-> LM head
-> logits
```

### Training Utilities

Implemented in [`cs336_basics/transformer_train.py`](./cs336_basics/transformer_train.py).

This file contains:

- stable cross-entropy loss;
- AdamW optimizer;
- cosine learning-rate schedule with warmup;
- gradient clipping;
- random batch sampling from tokenized datasets;
- checkpoint save/load helpers;
- validation loss evaluation;
- training loop with logging and checkpointing;
- top-p sampling and decoding helpers.

Tokenized datasets are intended to be stored as `uint16` binary arrays and read with `np.memmap`, which keeps loading memory-efficient for large datasets.

### Training / Data Preparation Entry Point

Implemented in [`cs336_basics/main.py`](./cs336_basics/main.py).

This script prepares TinyStories token ID files when needed, initializes a Transformer LM, creates log/checkpoint folders, and calls the training script.

## Data Preparation

The training code expects raw TinyStories files under `data/`, and tokenized `.bin` files can be generated by the data-preparation logic in `main.py`.

Token IDs are serialized as raw `uint16` bytes:

```text
TinyStoriesV2-GPT4-train.bin
TinyStoriesV2-GPT4-val.bin
```

This format can be read efficiently with:

```python
np.memmap(path, dtype="uint16", mode="r")
```

`uint16` is sufficient when the tokenizer vocabulary size is below 65536.

## Training

The training script supports:

- configurable model hyperparameters;
- configurable optimizer hyperparameters;
- warmup + cosine learning-rate schedule;
- gradient clipping;
- periodic training/validation logging;
- periodic checkpointing;
- best-checkpoint saving based on validation loss.

Example entry point:

```sh
uv run python cs336_basics/main.py
```

For GPU training on a remote machine, upload the source files, tokenizer files, tokenized `.bin` datasets, `pyproject.toml`, and `uv.lock`. Do not upload the local Windows `.venv`.
